# 찜꽁 레이더

우아한테크코스 공간 예약 페이지에서 원하는 시간대의 회의실·페어룸 상태를 빠르게 확인하고, 예약 입력과 Slack 공유를 더 쉽게 도와주는 Chrome 확장 프로그램입니다.

개편된 공간 예약 서비스(lms+)와 기존 찜꽁(zzimkkong) 예약 페이지를 모두 지원하며, 호스트로 서비스를 판별해 각 서비스에 맞게 동작합니다.

## 주요 기능

### 공간 레이더

- 예약 페이지에 회의실·페어룸별 시간 블록 레이더를 표시합니다.
- 30분 단위(lms+ 기준)로 예약 가능 / 예약 중 상태를 한눈에 볼 수 있습니다.
- 층별로 공간을 정리해 비교하기 쉽게 보여줍니다.
- lms+ 에서는 우측 하단의 원형 버튼으로 레이더를 열고 닫습니다.

### 빠른 예약 입력

- 타임블록을 클릭하면 날짜/시간/공간이 예약 폼에 바로 반영됩니다.
- 기본 60분(다음 칸이 예약이면 30분)으로 시간 범위를 자동 제안합니다.
- 시간 범위를 바꾸려면 예약 폼에서 시작 시간·이용 시간을 직접 수정합니다.

### 층별 평면도 (lms+)

- lms+ 에는 지도가 없어 공간의 물리적 위치를 알기 어렵습니다.
- 타임라인 아래에 층별 평면도(11/12/13F)를 접이식으로 붙여, 페어룸 등이 실제 어디에 있는지 확인할 수 있습니다.
- 평면도를 마우스로 누르고 있는 동안 화면 중앙에 크게 확대해서 볼 수 있습니다.

### Slack 메시지 복사

- 예약 생성 성공 후 Slack 복사 모달을 자동으로 엽니다.
- `/remind` 명령 생성, 채널 선택, 알림 시점 선택을 지원합니다.
- 채널은 combobox 형태로 입력하며, 이전에 사용한 채널을 다시 선택하거나 새 `#채널`을 추가할 수 있습니다.
- 선택된 채널은 chip 형태로 표시되며, 저장된 채널은 dropdown에서 다시 선택하거나 삭제할 수 있습니다.
- Slack 메시지는 자동 전송되지 않고, 사용자가 직접 복사해서 사용합니다.

## 사용 방법

1. 우아한테크코스 공간 예약 페이지에 접속합니다.
2. 확장이 로드되면 레이더가 표시됩니다(lms+ 는 우측 하단 원형 버튼으로 엽니다).
3. 날짜를 선택해 원하는 시간대의 공간 상태를 확인합니다.
4. 필요하면 타임블록을 클릭해 예약 폼에 날짜/시간/공간을 반영합니다.
5. 예약 완료 후 뜨는 Slack 모달에서 메시지를 복사해 사용합니다.

## 설치 방법

Chrome Web Store 게시 버전을 설치하거나, 개발용으로 직접 로드할 수 있습니다.

1. Chrome에서 `chrome://extensions` 열기
2. 우측 상단 `개발자 모드` 활성화
3. `압축해제된 확장 프로그램을 로드합니다` 클릭
4. 이 저장소 폴더 선택
5. 예약 페이지를 새로고침

## 참고 사항

- lms+ API 호출에는 사용자가 예약 페이지에 로그인하며 이미 보유한 인증 토큰을 같은 서비스 API 호출에만 재사용하며, 외부로 전송하거나 별도로 저장하지 않습니다.
- Slack 메시지는 자동 전송되지 않으며, 사용자가 직접 복사해 사용합니다.
- 예약 서비스의 화면 구조나 동작 방식이 변경되면 일부 기능이 정상 동작하지 않을 수 있습니다.

## 개발 참고

- 개발/테스트 문서: `DEVELOPMENT.md`
- 상세 API/회의실 매핑 문서: `ZZIMKKONG_MEETING_ROOMS_AND_API.md`
- 층별 평면도 SVG(`floor_map_*.svg`)를 수정한 뒤에는 `node scripts/generate-floor-maps.mjs` 로 `src/features/radar/floor-maps.js` 를 다시 생성합니다.

### GitHub 공개 전 확인

- `.env.example`을 복사해 `.env`를 만들고, 실제 guest URL/로컬 브라우저 경로 등 개인 설정은 `.env`에만 둡니다.
- `src-backup/`, `crews.csv`, `dist/`, `*.zip`, `test-results/`, `.DS_Store`, `.env*`는 공개 저장소에 올리지 않습니다.
- API 문서에는 실제 공유 맵 ID, 토큰, 비밀번호, 개인 식별자를 남기지 않고 placeholder를 사용합니다.

## 주의

- 이 확장 프로그램은 공식 제품이 아닌 비공식 보조 도구이며, 예약 서비스의 제휴·승인·후원을 의미하지 않습니다.
